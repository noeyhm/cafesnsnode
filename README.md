# 동네픽

동네 카페와 맛집의 신메뉴, 할인 소식, 방문 인증을 공유하는 모바일 로컬 피드입니다.

## 실행

1. Node.js 22.5 이상을 설치합니다.
2. 프로젝트 폴더에서 `npm install`을 실행합니다.
3. `.env.example`을 복사해 `.env`로 저장하고 `JWT_SECRET`을 임의의 긴 값으로 바꿉니다.
4. `npm start`를 실행한 뒤 `http://localhost:3000`을 엽니다.

SQLite는 Node.js 내장 모듈을 사용하므로 별도 DB 설치가 필요 없습니다. 첫 실행 시 데이터베이스와 예시 게시물이 자동으로 생성됩니다. 게시물 사진은 공개된 이미지 URL로 등록할 수 있습니다.

## 주요 기능

- 게시물 피드와 지역·가게·해시태그 검색
- 로그인 사용자의 게시물 작성, 좋아요, 댓글
- 회원가입 및 기존 아이디·비밀번호 로그인
- 모바일 화면 대응

## 데이터베이스

SQLite의 `users`, `posts`, `comments`, `likes` 테이블을 사용합니다. 데이터베이스 파일은 처음 실행할 때 `config/data/contacts.sqlite`에 생성됩니다.

카카오 로그인은 REST API 키와 Redirect URI 등록 등 카카오 개발자 설정이 필요하므로 포함하지 않았습니다. 현재 회원가입·로그인 기능을 사용할 수 있습니다.
